# Annoy nearest neighbors

Turn synthetic image colors into an ONNX embedding and rank three labeled reference vectors with an Annoy index.

Open [`annoy_search.json`](annoy_search.json) with **File → Open…**. Install the optional `annoy` extra, run once, and inspect **Annoy nearest neighbors**. The tiny ONNX model is a shared fixture.

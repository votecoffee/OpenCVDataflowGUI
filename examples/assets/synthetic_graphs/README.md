# Controlled synthetic graph fixtures

These are the original synthetic Demos and color/PLC graphs, retained byte for
byte during the real-photo migration. They provide known component counts,
geometry, colors, sequence motion and pass/fail criteria for automated tests.
Code-generated imagery and graph definitions are original project work (MIT).

The public [Demos tour](../../demos/README.md) now opens real photographs,
recorded frames and measured depth. The fixtures here are independent reference
cases, rather than showcase claims about real camera or industrial performance.
The shared synthetic validation PNGs remain under `../validation/`.

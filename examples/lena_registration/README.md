# Lena image registration

Rotate Lena by a known angle, match ORB descriptors, estimate the homography, and inspect the aligned difference.

Open [`lena_registration.json`](lena_registration.json) with **File → Open…**. Run `python scripts/prepare_lena.py` from the repository root first. Then run once and compare the estimated warp with the known rotation.

# Registered defect inspection ToolBlock

Align a sample to a reference with ECC, difference the images, and find defect blobs.

Use **ToolBlocks → Import ToolBlock…** to open [`registered_defect_inspection.toolblock.json`](registered_defect_inspection.toolblock.json). Import the definition and connect a reference and sample image. Try a translated sample with a visible defect and inspect the registered difference.

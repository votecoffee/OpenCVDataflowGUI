# Conveyor pick selection

**Data:** controlled synthetic fixture with explicit reference geometry or labels.

Find 25 fixed-scale parts and select a candidate using clearance and downstream position.

Open [`conveyor_pick.json`](conveyor_pick.json) with **File → Open…**. Run once and inspect **Select pick candidate**. The simulated obstacle mask demonstrates a clearance constraint.

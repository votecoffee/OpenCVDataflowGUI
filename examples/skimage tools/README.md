# scikit-image tools

Install `.[skimage]` in the application environment, then open a project:

| Example | Demonstrates |
| --- | --- |
| [Region properties](skimage_region_properties/README.md) | Comprehensive shape, topology, moments and per-channel measurements; filter a ring and reconstruct its mask. |
| [Advanced thresholding](skimage_thresholding/README.md) | Multi-Otsu classes, global estimators and local thresholds in original 16-bit intensity units. |
| [Skeletonization and pruning](skeleton_pruning/README.md) | Thin a binary shape using scikit-image and inspect the branches removed by pruning. |

These examples are grouped by their primary library, including a short chain
that also uses OpenCV or collection blocks. Related block contracts are in
[scikit-image inspection tools](../../docs/scikit-image.md).

# Color chart calibration

Detect a [bundled synthetic color chart](assets/synthetic_color_chart.png), fit a
correction model, and apply it to the image.

Open [`color_chart_calibration.json`](color_chart_calibration.json) with **File → Open…**. Run once and inspect the detected chart and corrected output. The fixture represents the OpenCV MCC24 reference colors with a synthetic channel cast.

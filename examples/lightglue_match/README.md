# LightGlue feature matching

Match a synthetic textured reference into a scene using SIFT features and LightGlue.

Open [`lightglue_match.json`](lightglue_match.json) with **File → Open…**. Follow the [LightGlue setup](../../docs/ml.md) for dependencies and weights, then run once and inspect the correspondences and fitted pose.

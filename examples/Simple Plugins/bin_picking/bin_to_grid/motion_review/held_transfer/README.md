# Recorded bin-to-grid review: held transfer

Open [project.json](project.json) and use **Run once** for recorded image and
colored-cloud review. This project reads saved evidence without starting ROS,
a simulator or robot motion. Select the review block's Cell parameter to browse
individual recorded cells. The retained transfer is held; no automatic motion retry is performed.

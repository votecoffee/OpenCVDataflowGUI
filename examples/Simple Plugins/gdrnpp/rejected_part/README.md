# SimpleGDRNPP: rejected part

Open a project below in OpenCVDataflowGUI. The app loads its Simple Plugin automatically.

| Project | Entry point |
| --- | --- |
| review project | [review_project.json](review_project.json) |
| run project | [run_project.json](run_project.json) |

Saved-result review projects run offline. Actual inference requires the configured
external worker and model weights; opening a project does not start them.

Original source, model and qualification notes are retained in the
[tool guide](../dev/README.md). Attribution also remains in the project comment blocks.

# SimpleSurfaceEnhance examples

Open a project below with **File → Open**, then use **Run once**. The app loads
the required Simple Plugin automatically. Each listed folder contains runnable
project JSON files directly; testing and development material is in `dev`.

| Example folder | Start here |
| --- | --- |
| [inspection](<inspection/README.md>) | [analytic_clean.json](<inspection/analytic_clean.json>) |
| [training](<training/README.md>) | [analytic_clean_trained.json](<training/analytic_clean_trained.json>), [connected_material_trained.json](<training/connected_material_trained.json>) |

The analytic and concrete-material lighting stacks are rendered controls,
including the CC0 concrete texture. They are not acquired camera measurements.

Use the block's Configuration popup to inspect or edit retained training. In
`training`, prefer a `*_trained.json` project when you want the finished staged setup.

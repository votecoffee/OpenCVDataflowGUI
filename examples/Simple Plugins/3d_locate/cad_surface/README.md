# Simple3DLocate · CAD surface

Train from a generated STL CAD part and locate two rotated copies with
independent surface sampling, measurement noise, clutter, and a missing slice.
Use Simple3DLocate **0.1.0.dev1 or later** in the DataflowGUI environment.

## Run and train

Open [project.json](project.json) and run once. Expect two poses in millimeters
mapping the taught `part` frame into the scene's `camera` frame.
The overlay and 3D `fit` cloud show supported/unsupported model samples and
pose axes. [assets/truth.json](assets/truth.json) contains the true transforms;
[expected.json](expected.json) records the verified result.

Open **Train 3D locator…** to restore the reference and retained CAD mesh.
Change **CAD surface samples** or **CAD sampling seed**, then train and test
using `assets/scene.ply`. Stage and Apply to save that training.
Import `assets/part.stl` with units **mm**, multiplier **1**, and outward
normals to teach a new recipe. Import requires an explicit unit selection.

CAD samples are weighted by triangle area. Candidate search uses a smaller
point budget; refinement and fit checks use the full trained surface.
The recipe retains the mesh and sampling settings for future resampling.

```powershell
simple-3d-locate train-stl assets/part.stl taught.s3l --units mm --frame part
simple-3d-locate locate taught.s3l assets/scene.npz
```

Rebuild with `python build_cad_demo.py . --host-project`.
[timing.json](timing.json) records first and cached local graph runs, including
file loading. Those measurements describe this synthetic example.

## Provenance and limits

The stepped part, STL, scene points and truth are generated by this example's
source and use the repository's MIT license.
The scene represents fused 3D observations with a missing spatial slice.
Single-view camera visibility, real sensor noise and dense bin-picking remain
separate qualification work.

The OpenCV surface-matching backend retains its
[published patent notice](https://docs.opencv.org/4.13.0/d9/d25/group__surface__matching.html).

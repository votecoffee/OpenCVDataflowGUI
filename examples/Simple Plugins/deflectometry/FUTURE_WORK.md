# SimpleDeflectometry remaining work

The first retained wrapped-phase reference-comparison workflow now has native
teaching, independent previews, staged application, cached execution and four
end-to-end examples. Follow-ups remain distinct from that software gate.

- Acquire distinct registered real reference/test captures with source exposure,
  response and known camera/screen geometry. The current SOFAST example is a
  code-diagnostic self-review. Independent repeatability/physical defect and
  surface truth remain unqualified.
- Decode absolute screen correspondence from coded/multi-frequency sequences,
  with ambiguity/discontinuity/occlusion evidence. Wrapped phase alone cannot
  reveal whole-period changes or support slope/height reconstruction.
- Integrate the separate assumed-plane reflection-normal API into retained
  physical setup/review once decoded screen U/V and calibrated geometry support
  it. Use native fly-around setup/ray graphics, labeled assumptions; never present
  those plane samples as a reconstructed measured surface.
- Estimate/qualify camera, screen shape/glass conventions, response and physical
  alignment. Explicit source/grid identity currently represents caller
  declarations, not verification of pose/exposure synchronization.
- Add richer masks and physical reference/registration checks. Current teaching
  retains arbitrary imported exact masks and edits rectangles with zoom/handles.
- Add learned repeatability/noise studies from multiple good references and
  independently evaluate change limits. Current optional radian limit is a
  user-defined phase-vector criterion, not a calibrated probability.
- Measure generic execution throughput, native multicore behavior and graphics
  cost; add bounded tiled/streaming capture beyond 16 million samples as needed.
  Current caching preserves reference fits/bases and supports parallel independent
  block instances; no application-specific tuning or measured speedup is claimed.
- Package external runtime manifest/image dependencies for portable project
  export. Sealed teaching assets copy with Save As; ordinary capture files remain
  references to their existing source folders.
- Color/single-shot Fourier processing, multibounce/transparent samples,
  stereo/multiview reconstruction and anchored absolute shape remain later work.

Advancing delivery focus does not mark physical calibration/accuracy or these
additional algorithms complete.

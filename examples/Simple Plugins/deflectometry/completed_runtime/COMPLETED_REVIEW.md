# Completed reflected-pattern and phase-change review

Run a configured SimpleDeflectometry block in Debug, then open **Review completed
patterns and phase changes…** from its inspector. This read-only popup is
independent of reference teaching. A failed configured inspection still supplies
evidence; unexecuted, active, exception and unretained Lean results cannot.

The paired capture freezes the actual consumed native X/Y stacks, masks, metadata,
sequence/setup/grid/radiometry declarations; exact executed `.sdef` bytes and
reference/mask/phase/decision settings; consumed manifest when used; full report;
all 18 maps and any emitted rasters. It never substitutes training images for
inspection or follows current upstream values. Manifest-only runs use the host's
empty paired-input SDK support (da6de1a4 or later).

Select an observed X/Y frame, actual source or executed reference, completed map
and X/Y map component. The initial view shows the emitted change/rejection overlay
when available. These controls are independent and labeled. Shift-click a
source-grid image or use X/Y to inspect its exact pixel. Wheel zoom, drag pan,
Focus pixel and Overview support fine assessment. Overview panels have display
coordinates and cannot be picked as source pixels. Cyan marks the reference ROI
used as the coverage denominator; test masks can only reduce comparability.

The table and chart show stored normalized reference/inspection pattern codes,
declared shifts, ceiling/nonfinite states, and the recorded circular X/Y change
vector. The vector chart uses fixed -pi..pi axes and the configured limit circle.
No per-frame fitted prediction or residual is stored, so none is invented.
Raw map NaNs/types/values remain unchanged; colors/ranges only affect display.

Comparison reasons distinguish comparable, outside reference ROI, unavailable
reference, unavailable test and both unavailable. Per-axis phase reasons explain
the underlying signal/fit rejection. The change map is signed and circular;
magnitude and an optional threshold are user-selected phase criteria, not
probabilities or calibrated defect labels. A disabled criterion remains disabled.
The near-wrap-boundary flag cannot detect every whole-period change.

**Whole-period ambiguity always remains.** Unknown exposure/response in
`uncalibrated_codes` stays explicit. The supported phase-only block has no absolute
screen correspondence, measured normal/slope, height or cloud. The separate
assumed-plane reflection API is not run by this review.

New publications mark the review stale without replacing it. **Capture latest
completed run** explicitly replaces the snapshot only after a successful paired
capture; failed recapture keeps the old one visible. Pending teaching/region/
radiometry/limit edits and Stage/Apply/Cancel remain independent. Closing releases
snapshot arrays and all displayed pixmaps.

**Export frozen review…** writes a new exclusive folder: byte-identical executed
recipe and original consumed manifest, actual native X/Y/mask/declaration arrays
with dtype/shape/hash records, separate reference arrays/mask, every raw map and
emitted raster, and source/reference/selected-map/overview/observation/assessment
PNGs. JSON retains identities, limits, reasons, selected pixel and scope. Original
encoded camera-image bytes are not retained, only actual normalized consumed arrays.
Unknown extra capture fields are listed as ignored. Data licenses apply to retained
and derived data independently of the tool's original code license.

Capture/browse/export never reload files, refit phase, unwrap, solve reflection,
calibrate, change acceptance or edit training. Debug retains references and compact
correlation metadata; deep array copies occur only on explicit review capture.
Lean skips review retention. Graphics-off keeps maps/judgment while emitted rasters
remain absent; review can color frozen maps without running analysis again.

Caller identities and low residuals do not prove registration, synchronization,
absolute correspondence or physical accuracy. SOFAST same-capture self-review
establishes import/fit/replay behavior, not held-out inspection performance.

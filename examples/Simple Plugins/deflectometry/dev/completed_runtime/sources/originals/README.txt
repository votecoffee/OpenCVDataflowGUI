
This directory contains files associated with a measurement of a Sandia National Solar Thermal Test Facility (NSTTF) heliostat facet using SOFAST Fringe.

This data was captured using the SOFAST Landscape setup in the NSTTF Optics Lab.  See:
    OpenCSP_Mechanical/Sandia/OpticsLab/SOFAST_Landscape/Sandia_OpticsLab_Landscape.SLDASM

Subdirectory content:

1_images_fringes_projected
--------------------------
The image data files projected onto the screen by the SOFAST projector.

2_images_captured
-----------------
The image data files captured by the SOFAST camera, looking at the NSTTF facet.

3_processed_data
----------------
The key file here is the "data_sofast_processed.h5" file.  This file was generated by the SOFAST program, and includes multiple SOFAST computation data objects, stored in HDF5 format.

See below for information on HDF5View, and a viewer to access the contents of the HDF5 file.

To see an outline of the contents of this HDF5 file, see the screen shot image:
   3_processed_data/data_sofast_processed_tree.png
using any image viewer.

This directory also contains the "measurement_statistics.json" file, which contains several primary measurement statistics.  This file can be viewed in a text editor.

4_processed_output_figures
--------------------------
Output measurement and analysis plots.



HDF5 Files and How to View Them
===============================

HDF5 is a file format which can store large amounts of heterogeneous data in a hierarchical format.

See below for information on HDF5, and a viewer to access the contents of the HDF5 file.

For general description information, see:
    https://en.wikipedia.org/wiki/Hierarchical_Data_Format
    https://docs.hdfgroup.org/hdf5/v1_14/_intro_h_d_f5.html

HDF5 data can be viewed using a variety of viewer programs.

HDF5View is one that we use:
    https://www.hdfgroup.org/
    https://www.hdfgroup.org/downloads/hdfview/
When we attempted access on September 11, 2024, the above link was not working.

But we found download information here:
    https://portal.hdfgroup.org/downloads/index.html
    https://portal.hdfgroup.org/downloads/hdfview/hdfview3_3_2.html

The above provides a User Guide.  Here is where you can find downloadable executables:

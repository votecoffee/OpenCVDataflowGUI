# Image sources and changes

Hyun Soo Kim (2024), **Weld bead images and masks**, Figshare version 1.
[Dataset DOI](https://doi.org/10.6084/m9.figshare.25904014.v1) ·
[Primary metadata](https://api.figshare.com/v2/articles/25904014/versions/1).
Primary version-1 metadata was checked on **2026-11-18** and reports **MIT**,
author **Hyun Soo Kim**. The complete publisher copyright and license text is
retained in [WELD-LICENSE-data.txt](WELD-LICENSE-data.txt).

This increment reuses prepared public assets from archive file ID `46550428`;
no dataset archive was downloaded. These photographs and matching supplied
`_mask.png` files retain their existing filenames and bytes under `weld/assets`:

- `20230930_21h03m42s_B11_1.png`: training reference and first replay.
- `20231113_19h46m30s_B13_3.png`: separate replay.
- `20231114_11h25m52s_B04_3.png`: failing replay.

Existing recipes keep the grayscale reference and original detector settings.
Additional derivatives are planned scan/search-band graphics, measured reference
station overlays, display crops, native profiles/trends and the combined gallery.
The staged recipe stores the same path through an authored affine-coordinate
control. It does not claim a real CAD fit or verified dimensional ground truth.
The original failing weld replay remains a failure; weak/unrelated edge choices
remain visible. Dataset authors do not endorse this tool.

The calibrated bead, its planar mapping and generated landmark controls are
authored simulations. They are not acquired-camera or physical calibration
evidence. Authored controls/code and the bundled tool use the included
[MIT license](LICENSE); the wheel includes its own license notice.

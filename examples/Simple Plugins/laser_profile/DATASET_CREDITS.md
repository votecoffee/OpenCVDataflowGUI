# Dataset and dependency credits

## WLI-Set version 3

**zeng song** (creator name as listed by Figshare), *WLI-Set: A Comprehensive
Laser Image Dataset for Real-Time Measurement of Wheelset Geometric Parameters*,
version 3, Figshare, DOI
[10.6084/m9.figshare.25040747.v3](https://doi.org/10.6084/m9.figshare.25040747.v3).

The [versioned dataset record](https://api.figshare.com/v2/articles/25040747/versions/3)
declares [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
License metadata and attribution were checked on 2026-11-16. This is permission
to reuse the dataset under its stated terms, not an endorsement by its authors.

Four original JPEGs and their published binary centerline PNGs are redistributed
byte-for-byte in `studies/wli/origin` and `studies/wli/centerline`. They are the
first, one-third, two-thirds and last sorted original basename, selected before
running the extractor. The teaching ROI is a separate annotation; originals and
reference masks are not painted, cropped or rescaled. Overlays, profile plots and
numeric comparisons are derived results; this notice and the original dataset
attribution apply to the dataset-derived review images.

`studies/wli/provenance.json` records immutable Figshare file IDs, member sizes,
CRC32 and local SHA-256 hashes. The publisher's whole-ZIP MD5 values are retained
as metadata, not claimed as locally rehashed archives. Only selected members and
the nested centerline archive were fetched using bounded HTTP ranges.

The associated publication is
[A comprehensive laser image dataset for real-time measurement of wheelset geometric parameters](https://pmc.ncbi.nlm.nih.gov/articles/PMC11074251/).
The supplied centerlines are industrial-software references; nearest-reference
pixel distance is not physical height accuracy or stripe-identity ground truth.
The selected images do not supply camera/laser-plane calibration. They remain
pixel-only examples and do not generate metric point clouds.

## Generated control

`studies/calibrated_control` uses images generated by the included original
example builder with known pinhole geometry, two target depths and an independent
50-mm test step. This is software development evidence, not measured optical or
metrology qualification. Original generated assets use this package's MIT license.

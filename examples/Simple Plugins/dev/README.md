# Simple Plugins development material

Shared result-view builders and the historical real-data review gallery live here.
Each tool also has a `dev` folder for its own tests, builders, pinned old versions,
source notes and qualification evidence. These are excluded from normal example search.

The [folder layout map](layout.json) records runnable folders and old-to-new directory moves.

# Inspect shapes ToolBlock

Reuse threshold and contour inspection with a nested preprocessing graph.

Use **File → Open…** to open [`inspect_shapes.toolblock.json`](inspect_shapes.toolblock.json)
in a new project. Use **ToolBlocks → Import ToolBlock…** to add it to a project
you already have open.

Connect a Demo image source to its public image input, and inspect its outputs and internal graph.

# Registered defect inspection ToolBlock

Align a sample to a reference with ECC, difference the images, and find defect blobs.

Use **File → Open…** to open [`registered_defect_inspection.toolblock.json`](registered_defect_inspection.toolblock.json)
in a new project. Use **ToolBlocks → Import ToolBlock…** to add it to a project
you already have open.

Connect a reference and sample image. Try a translated sample with a visible defect and inspect the registered difference.

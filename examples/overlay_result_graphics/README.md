# Overlay result graphics

Draw a region outline and contour annotations on the original color image.
The contours are measured on a separate thresholded branch.

Open [`overlay_result_graphics.json`](overlay_result_graphics.json) with
**File → Open…** and run once in **Debug**. Select **Overlay result graphics**
and inspect its **Result / image**. Use **Choose graphics…** to uncheck either
layer, click **Apply configuration**, and run again to compare.

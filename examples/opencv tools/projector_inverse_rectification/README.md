# Prewarp a calibrated projector pattern

Open `projector_inverse_rectification.json` and run once. Compare the
**Ideal six-fiducial pattern**, the native projector raster from
**Prewarp for projection**, and **Restore ideal view** after the forward
lens map. The example includes a 430 × 316 ideal pattern, a 320 × 240
projector, Brown lens distortion, and a small rotation between the axes.

The prewarp reports 76,780 of 76,800 supported projector pixels.
The native forward/inverse check gives an image correlation of 0.99991.
A separate Brown projection calculation in the tests places all six
markers within 0.02 ideal-view pixels of their expected positions on a
synthetic oblique target. `assets/target_truth.json` records the physical
target coordinates and corresponding projector pixels. These checks run
offline with simulated optics.

Connect a projector model or a calibrated camera/projector rig. Use a
distortion-free **Pattern camera** when the ideal raster has known
intrinsics. Without that input, the block scales the projector intrinsics
to the ideal raster using the pixel-center convention. Enter the
Rodrigues rotation from raw projector axes to ideal pattern axes in radians.

**Valid mask** shows the forward-visible pixels with sufficient source
support for the selected interpolation. The warped image fills other
pixels with the configured border value. A low-coverage or sampled
reprojection failure emits a report and mask and withholds the raster and
maps. The round-trip check samples the raster and does not certify optics
outside the tested rays.

The paired float maps store ideal pattern donor coordinates for each
projector pixel. Replay on the original pattern grid with the same
interpolation and constant border. For packed maps, select Nearest
packing for nearest-neighbor sampling and Subpixel packing otherwise.

The pattern and calibration geometry were generated by
OpenCVDataflowGUI contributors under the project's MIT license.
Run `build_example.py --output <empty directory>` to recreate them.

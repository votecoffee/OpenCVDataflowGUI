# Rectify three collinear cameras

Open `collinear_stereo.json` and run once. The **Common-row rectification**
block aligns the three images to a shared horizontal grid. Two **Stereo BM /
SGBM disparity** blocks use the 54 mm and 117 mm baselines. Each depth branch
compares its result with an independently specified plane at **1150 mm**.

| Baseline | Target row RMS | Depth coverage | Dense depth RMSE |
| --- | ---: | ---: | ---: |
| 54 mm | 0.0000029 px | 85.3% | 24.6 mm |
| 117 mm | 0.0000026 px | 80.2% | 13.7 mm |

The example checks 70 matched target points per baseline across two captures
separate from the textured well-lit plane used by the dense matcher. Subpixel
disparity errors still produce depth error, especially on the short baseline.

Connect the images in calibration order. Supply either a three-camera
**Calibrate multi-camera rig** result or three same-size pinhole models and
two reference-to-camera poses in matching metric units. **Check** accepts
optional held-out observations. It matches shared target IDs for each pair
and can reject excessive row misalignment. The center-offset limit controls
how far the measured third center may depart from the baseline. Accepted
offsets are projected onto the baseline for the horizontal disparity model.

Use **Reference 12** with **Second** and **Rectification 12**, and
**Reference 13** with **Third** and **Rectification 13**. The reference pixels
are identical and each carries its own paired grid identifier. Wire the
validity masks to the matching left and right mask inputs. `Alpha` controls
the crop for the reference/second pair. The third camera can have uncovered
areas even when the first pair uses a tight crop.

The pinned Python wheel exposes pairwise stereo rectification. The block
extends this geometry to the third camera using the measured pose, with one
signed disparity-to-depth matrix per baseline.
[OpenCV stereo API](https://github.com/opencv/opencv/blob/5.x/modules/stereo/include/opencv2/stereo.hpp)

The images, target observations and depth reference were generated by
OpenCVDataflowGUI contributors under the project's MIT license.
Run `build_example.py --output <empty directory>` to regenerate the fixture.

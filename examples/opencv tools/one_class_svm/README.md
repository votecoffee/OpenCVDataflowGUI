# One-class image anomaly inspection

Open train.json and choose **Run all**. The graph loads 20 known-good groove
images, computes HOG descriptors, then trains after the full batch arrives.
Connect its Model output to **Save one-class SVM model** to write a new reference.
The inspection graphs load the bundled reference and each run once.

| Project | Expected outcome |
| --- | --- |
| [train.json](train.json) | Train on 20 known-good windows and reproduce the stored reference. |
| [normal.json](normal.json) | Accept a separately generated normal part at raw margin about +0.144. |
| [defect.json](defect.json) | Reject a part with a synthetic gouge at raw margin about -0.101. |
| [tilted_good.json](tilted_good.json) | Reject a defect-free image with orientation outside the training range. |
| [strict_cutoff.json](strict_cutoff.json) | Apply a sealed 0.2 margin cutoff. The same normal image remains a native inlier and the stricter inspection rejects it. |
| [wrong_features.json](wrong_features.json) | Reject changed HOG gamma correction even though the descriptor length is unchanged. |

The fixtures use original synthetic MIT images generated by build_example.py.
Training uses seeds 0 through 19. The normal and defect controls share unseen seed
101 so the synthetic gouge is their only image difference. The tilted control
uses unseen seed 102. The fixtures demonstrate software behavior on controlled
images. Inspect the separate tilted control to see why production training needs
representative nuisance variation and independent validation.

truth.json records the assets and their expected decisions. Rebuild into a new
directory with build_example.py --output PATH.

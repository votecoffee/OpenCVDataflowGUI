# Third-party material

`bundle/model.onnx` is the unchanged OpenCV Zoo
`pose_estimation_mediapipe_2023mar.onnx`, released by the OpenCV Zoo contributors
under Apache License 2.0. It derives from the MediaPipe Pose model; the upstream
[model page](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/pose_estimation_mediapipe)
retains conversion and original model references. A complete copy of its license
is included as [LICENSE.opencv-zoo](LICENSE.opencv-zoo).

`assets/astronaut.png` retains NASA's photograph of Eileen Collins, documented
as public domain by scikit-image. Its attribution and pixel-preserving PNG
re-encoding are recorded in [SOURCES.md](SOURCES.md).

The original application graphs and adapter/reference code use the repository's
MIT license. These notices retain the separate terms for the included assets.

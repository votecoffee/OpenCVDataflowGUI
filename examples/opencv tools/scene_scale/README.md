# Recover metric scene scale

Open [scene_scale.json](scene_scale.json) and run once. Four calibrated
pinhole views observe 26 landmarks from different positions. Their camera
translations are in one shared unitless frame. The first block reconstructs
the cloud with those views. The second fits a metric similarity transform
from landmark IDs and surveyed XYZ coordinates, then emits the cloud and
camera poses in the survey frame.

| Check | Result |
| --- | ---: |
| Known meters per reconstruction unit | 0.180000 |
| Recovered meters per reconstruction unit | 0.179974 |
| Accepted training anchors | 9 of 10 |
| Independent holdout targets | 8 |
| Holdout RMS error | 0.740 mm |
| Largest holdout error | 1.234 mm |

A deliberate bad training coordinate for P02 is rejected. The holdouts
are excluded from the fit and are evaluated after the fit. Inspect the
report for individual residuals, then open the metric point cloud or
inspect the extent measurement.

Supply a `metric_landmark_controls_v1` object through the Controls
parameter or input. Enter a named target `frame`, `units` (`m` or
`mm`), and `anchors` and optional `holdouts` lists. Each record contains
one landmark `id` and its measured `xyz` coordinates. Use at least three
non-collinear anchors with the same IDs as the reconstructed cloud.
The training and holdout IDs must be disjoint. A missing holdout or a
holdout error over the configured limit withholds metric outputs.

Output coordinates and pose translations are in meters. The similarity
records a positive uniform scale, a proper rotation, and a translation.
This workflow requires camera poses already expressed in the same
unitless gauge, including consistent baseline ratios. It leaves
intrinsics and image observations unchanged. [OpenCV similarity transform reference](https://docs.opencv.org/doc/doxygen/html/d2/d48/group__d__projection.html)

The observations and [fixture truth](assets/ground_truth.json) are synthetic
and were generated by the OpenCVDataflowGUI contributors (MIT). Rebuild the
files with `python build_example.py --output <new-directory>`.

# Thin-plate spline registration

Open [thin_plate_spline.json](thin_plate_spline.json) and choose **Run Once**.
**Register plate** pulls original plate pixels onto the target grid using 30
paired landmarks. Green rings mark the target controls and larger yellow
rings mark six test points held out of the fit. **Residual to known warp**
shows the absolute difference from the independently generated target.

| Measurement | Result |
| --- | ---: |
| Maximum control-point error | 0.000104 px |
| Held-out landmark RMS error | 0.320 px |
| Maximum held-out error | 0.359 px |
| Mean per-channel image error before registration | 12.24 levels |
| Mean per-channel image error after registration | 1.16 levels |

**Register image (thin-plate spline)** is under **OpenCV → Shape Distance
and Matching → Registration**. Supply ordered source and target control
points in their respective image grids. You can enter point lists in the
settings or wire the data connectors. Spread matching landmarks across both
axes and over the area you want to inspect. The block accepts 4–64 pairs.
Regularization smooths the fit in normalized coordinates. Zero interpolates
the controls.

The optional target image sets the output size and coordinate frame.
Framed target control points can also supply this grid. Otherwise the
output uses the source dimensions and a new coordinate frame. Optional
probe points map from target pixels to the source coordinates used for
sampling. Wire or enter known source probe positions to report their error.
The fit uses OpenCV's thin-plate spline and samples through its inverse
mapping with the selected interpolation and border options.
[OpenCV thin-plate spline reference](https://docs.opencv.org/5.0/main_modules/classcv_1_1ThinPlateSplineShapeTransformer.html)

The original MIT images and the analytic deformation are generated by the
example builder. Rebuild from the repository root.

    python "examples/opencv tools/thin_plate_spline/build_example.py" --output "examples/opencv tools/thin_plate_spline"

# Refine calibration target geometry

Open `refine_calibration_target.json` and run the two fits on the same
observations. **Release target** estimates the shared 3D target coordinates.
**Fixed target** uses the nominal flat coordinates as a control. Both use a
121.2 mm measured baseline and the same 13 fit views. Three separate
holdout views estimate pose from alternating target points and score the
remaining points. Expect about 0.037 px holdout RMS for the released target
and 0.730 px for the control. The control deliberately fails the 0.20 px
holdout limit, so the headless project exits with a failed inspection.

Compare the standard pinhole `calibration` output, `report`, and `target`.
Inspect **Target offsets** in the Debug profile. The target output includes
nominal and refined XYZ, per-coordinate OpenCV standard deviations and a
fixed-coordinate mask. OpenCV fixes every coordinate of point 0 and the
selected anchor, plus Z of the final point. The reported standard
deviations condition on those constraints. The measured anchor distance
sets the overall scale of the nominal board about point 0.

Supply an ordered JSON file through **Load calibration target observations**
or pass the same record from another block. The file in `assets` is a
working reference.

| Key | Value |
| --- | --- |
| `model` | `pinhole_target_observations_v1` |
| `target_id` | Identifier of one rigid target |
| `units` | `mm` or `m` |
| `image_size` | `[width, height]`, shared by all views |
| `object_points` | 10–128 ordered nominal `[X,Y,0]` rows |
| `views` | 5–32 objects with a unique `id`, role `fit` or `holdout`, and `image_points` in the same order as the object points |

Use at least four varied fitting views and a separate holdout. Every view
must include the full target in consistent point order. A measured
baseline requires its explicit point index. Choose nominal anchor
coordinates and target orientation that match the physical reference.
Holdout error measures reprojection on the supplied target and poses.
Physical dimensional acceptance requires independent target measurements.
[OpenCV camera calibration API](https://github.com/opencv/opencv/blob/5.x/modules/calib/include/opencv2/calib.hpp)

The observations and target are synthetic, generated by
OpenCVDataflowGUI contributors for this MIT-licensed example. Run
`build_example.py --output <empty directory>` to reproduce the files.

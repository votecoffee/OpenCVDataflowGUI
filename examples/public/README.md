# Public examples

Open a project with **File > Open** in OpenCVDataflowGUI and press **Run once**.
The projects use bundled openly licensed images and built-in blocks. They can run offline.

| Project | What it shows |
| --- | --- |
| [Brick edges](brick_edges/README.md) | Reduce texture noise and find mortar edges. |
| [Coffee histograms](coffee_histograms/README.md) | Compare BGR histograms with a single grayscale histogram. |
| [PCB outline](pcb_outline/README.md) | Isolate a blue circuit board in two real inspection images and overlay its contour. |

Keep the `assets` folder beside the project folders so the saved relative
image paths resolve. See [image sources and licenses](assets/README.md).

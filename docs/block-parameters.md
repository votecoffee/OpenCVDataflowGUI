# Block parameter reference

Generated by `python scripts/block_parameter_reference.py`. Defaults and enum choices
come from the same metadata used by the inspector, along with declared numeric limits.
Enums are dropdowns, booleans
are checkboxes, and vectors/matrices use JSON fields. Image/data inputs are ports,
not hidden parameters. Native output buffers, in-place pointers and backend internals
are managed by the runtime. Some controls apply only to the selected method or codec.
Image inputs also have an inspector pyramid-level dropdown (largest by default).
See [payloads, channels and pyramids](payloads-pyramids.md) for coordinate provenance.
Input sources also expose ticket input/output ports and inspector ticket mode/fixed value
controls. See [tickets and control flow](control-flow.md) for their shared configuration.
Every input has a failure-policy dropdown: continue (default) or reject_failed.
See [ticket results](ticket-results.md) for outcomes and final judgments.
Processing/acquisition parameters can use inspector Recipe overrides paths; trainable
matchers can bind a recipe model. See [recipes](recipes.md) for scope and revision rules.

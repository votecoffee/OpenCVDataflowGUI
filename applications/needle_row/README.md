# Needle row

After [loading the trusted matcher plugin](../README.md), open
[inspection.json](inspection.json) and replay the full set. The first scene
has 19 needles. The second has three empty slots, leaving 16 needles.
The third is empty and produces a failed inspection with zero matches.

The datum sits near the hub of each needle. Inspect the cyan axes to
compare their positions and orientations along the row.
